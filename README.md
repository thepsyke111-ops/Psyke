# Psyke! — free static website

This is a no-build static website recreated from the Psyke! screenshots.

## Files
- `index.html` — Home
- `content.html` — Content
- `about.html` — About + Founder
- `contact.html` — Contact
- `faqs.html` — FAQs
- `style.css` — styling
- `script.js` — contact form mailto behaviour
- `assets/` — image assets cropped from the supplied screenshots

## Free publishing
The easiest free option is GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `psyke`.
3. Upload all files and the `assets` folder.
4. Open repository Settings → Pages.
5. Choose “Deploy from a branch”, select `main` and `/ (root)`, then Save.
6. GitHub will give you a public `github.io` address.

The contact form opens the visitor's email app and prepares an email to `thepsyke111@gmail.com`; it does not require a paid backend.
